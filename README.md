# Ester Alves Fotografia

Site estático em português para Ester Alves, Belo Horizonte e Grande BH.

## Publicar no GitHub Pages

Envie o conteúdo de `dist/` para a raiz do repositório. Em Settings > Pages, selecione Deploy from a branch e a pasta raiz da branch principal. O site também funciona em um subdiretório do GitHub Pages porque usa caminhos relativos.

O domínio próprio pode ser configurado posteriormente. O site não depende de servidor, Node ou processo de build.

## Conteúdo

- `dist/index.html`: seções, textos e metadados.
- `dist/style.css`: paleta, tipografia e versões responsivas.
- `dist/app.js`: categorias, galerias, menu e mensagens de WhatsApp.
- `dist/assets/`: recortes das capturas fornecidas para a primeira versão conceitual. Substitua pelas fotografias originais antes de divulgar o portfólio definitivo.

A área sobre a fotógrafa utiliza o retrato enviado da Ester com a câmera. A biografia foi limitada às informações fornecidas. As categorias sem fotografias convidam a solicitar referências, sem utilizar imagens de terceiros.

O Instagram contém nove imagens selecionadas manualmente e links para o perfil; não é um feed automático. A atualização automática exigirá conexão autorizada e serviço/API apropriado. Nenhum token deve ser incluído no JavaScript público.

WhatsApp configurado exatamente como fornecido: https://wa.me/553194184748. Confirme o recebimento das mensagens antes do lançamento público.

As fontes são carregadas do Google Fonts, com alternativas locais de fallback.

Atualização de conteúdo: biografia de 8 anos de profissão, estúdio no Guarani, orientações para ensaios, condições de reserva, escolha e entrega das fotos e perguntas frequentes. Informações fornecidas pela fotógrafa. Categorias adicionadas: aniversário, Smash the Cake e família.
